**Vedanshu Nishad** — 24BCS10285 — Batch B

Shell scripting tasks from `session3/task.md`. All 10 scripts are standalone.

## How to run

```bash
chmod +x *.sh
./input.sh        # interactive scripts ask for input
```

## Scripts and tasks

| Script | What it does | Covers |
|---|---|---|
| `task.sh` | Prints current date, hostname and username; saves `ps` output to `process.log`; reads name, roll number and comment | date, hostname, username, process list, process.log, input |
| `variable.sh` | Prints name, roll number and comment from variables | variables |
| `input.sh` | Reads name, roll number and comment from the user with `read -p` | take input |
| `data.sh` | Creates a `data1/` directory and writes to `app.log` | create file and directory |
| `condition.sh` | Reads age and prints child / teenager / adult | if-elif-else |
| `loop.sh` | Prints iterations 1 to 5 | for loop |
| `loop_task.sh` | Sums 1 to n (input) using a for loop | for loop |
| `loop_task_while.sh` | Sums 1 to n (input) using a while loop | while loop |
| `while_loop.sh` | Prints iteration numbers 0 to 4 | while loop |
| `function.sh` | Defines and calls a function | functions |
