Session 19 Mini Project

The Terraform cloud infrastructure is working.

This page was uploaded to a private S3 bucket by Terraform. The EC2 instance downloaded it using an IAM role and serves it through Nginx.

  • VPC and subnet provide the network.
  • The Internet Gateway and route table provide internet access.
  • The Security Group allows HTTP traffic on port 80.
  • EC2 runs the web server.
  • S3 stores index.html.
